# The Flux Comic

I have wanted to start a comic for a very long time. I have always had the concepts and the stories in my head, but I lacked the technical ability to draw them. For years, these ideas just stayed in notebooks because I could not bridge the gap between the thought and the image.

Recently, the technology behind Gemini and its Nano Banana 2 model changed that for me. It allows me to use my words to generate the images you see here. To be clear, I do not personally consider these images to be art. In my view, art requires a human being to create the work by hand. While others might feel differently, I see these as a way to finally get my ideas out into the world.

This repository serves as a daily archive for these posts. It is a place for me to organize the journey and share the results of this collaboration between my ideas and the tool.

## License and Usage
