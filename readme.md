# The Flux Comic

I have wanted to start a comic for a very long time. I have always had the concepts and the stories in my head, but I lacked the technical ability to draw them. Ideas were lost, or captured on computers and hard drives that no longer exist.

Recently, the technology behind Gemini and its Nano Banana 2 model changed that for me. It allows me to use my words to generate the images in a good enough way. To be clear, I do not personally consider these images to be art. In my view, art requires a human being to create the work. While others might feel differently, I see these as a way to finally get my ideas out into the world.

This repository serves as a (hopefully) daily archive for these posts. It is a place for me to organize and share the results of this collaboration between my ideas and the tool.

## License and Usage

Though the concepts and text are mine, the images are computer created. You are welcome to share, use, or build upon these comics for any purpose you like. 

The only requirement is that you provide attribution to Curt Meinhold and include a link to TheFlux.com.
